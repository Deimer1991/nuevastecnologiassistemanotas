 ****Sistema de Notas en Python****

Aplicación desarrollada en Python que permite gestionar estudiantes y sus notas desde la consola mediante un menú interactivo

El programa permite registrar estudiantes, registrar notas y calcular promedios de forma sencilla


****Características****

* Menú interactivo utilizando un ciclo 
* Registro de estudiantes
* Registro de notas para cada estudiante
* Cálculo del promedio individual
* Visualización de la lista de estudiantes registrados
* Uso de funciones para separar la lógica del programa

---

****Conceptos aplicados****

Este proyecto demuestra la implementación de:

* Ciclos (while)
* Condicionales (if / elif / else)
* Funciones en Python
* Manejo de listas o diccionarios
* Organización del código en módulos
